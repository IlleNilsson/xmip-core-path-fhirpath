# xmip-core-path-fhirpath

FHIRPath path technology: navigation, indexing, where, select, first, last,
count and exists over a FHIR JSON resource, the first item read and written,
for promote, demote, route and process. A technology of
[xmip-core-path](https://github.com/IlleNilsson/xmip-core-path).

## Toolchain

`rust-toolchain.toml` pins the toolchain for the whole estate. Do not change it
here.
